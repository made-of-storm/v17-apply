### Шаги в Google Search Console

1. Зайти на https://search.google.com/search-console
2. Выбрать свойство **https://v17.vc** (если нет — добавить, подтвердить через DNS или HTML-тег Тильды)

## 9–10. Производительность PageSpeed (⚠️ главная правка — Тильда)

### Почему desktop «не сканирует» /policy и /what-are-v17s-3-tracks

В HEAD всего сайта Тильды стоит скрипт, который на **первом заходе с экрана ≥980px** прячет **всю страницу** (`opacity: 0`) на ~400 мс, потом плавно показывает. Это не «скрытый контент» — анти-мигание при загрузке.

PageSpeed Insights подставляет обычный Chrome (не бот) + медленную сеть → страница не успевает отрисоваться → ошибка **NO_FCP**. На главной много картинок — тест проходит; на текстовых страницах — нет.

### Инструкция: убрать fade-in скрипт

1. Войти в Тильду → проект **v17.vc**
2. **Настройки сайта** (шестерёнка) → **Ещё** → **HTML-код для вставки внутрь HEAD**
3. Найти скрипт, внутри которого есть строки:
   ```
   .t-records {opacity: 0;}
   t-records_visible
   sessionStorage.setItem("visited"
   ```
4. **Удалить весь этот `<script>…</script>`** (или закомментировать)
5. **Сохранить** → **Опубликовать все страницы**
6. Проверить в PageSpeed Insights (режим Desktop):
   - https://v17.vc/policy
   - https://v17.vc/what-are-v17s-3-tracks

*Побочный эффект:* при первой загрузке на десктопе может на долю секунды мелькнуть «сырая» вёрстка. Зато PSI перестанет падать с NO_FCP.

### Шрифты (в том же HEAD или в настройках проекта)

Сейчас на страницах **два** render-blocking запроса к Google Fonts (Manrope дублируется).

1. В HEAD оставить **один** link, например:
   ```html
   <link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700&family=Urbanist:wght@500;600&display=swap" rel="stylesheet">
   ```
2. Второй дублирующий `<link href="...Manrope...">` — удалить
3. Опубликовать

### Главная страница (уже ~91 desktop — по желанию)

- На LCP-картинку первого экрана в Zero Block добавить `fetchpriority="high"` (режим HTML элемента)
- Скрипт `cdn.postnikovmd.com` (flip-карточки) уже только на mobile (`max-width: 980px`) — на desktop не влияет

### Страница /apply

- Контент в iframe — PageSpeed **никогда не покажет полный отчёт** по форме, только оболочку Тильды. Это нормально.
- Не ставить `loading="lazy"` на iframe (см. `tilda-apply-page.html`)
- После деплоя формы с `noindex` — меньше путаницы в индексе
